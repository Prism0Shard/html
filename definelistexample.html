Web Developement Terms

HTML:
Hyper Text Markup Language used to structure content on webpages.
CSS:
Cascading Style Sheets. A styling language used to control the visual look, layout, and design of webpages.
JavaScript:
A High-Level programming language used to add dynamic behavior and interactive features to websites.
Server:
A server is a hardware device or software that processes requests sent over a network and replies to them. It can host websites, manage databases, and provide various services to clients.
Browser:
A computer program with a graphical user interface for displaying and navigating between web pages. Examples include Google Chrome, Mozilla Firefox, and Microsoft Edge.
